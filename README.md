## ✨ Core Features

This portfolio is more than just a static page; it's a feature-rich application designed to demonstrate modern web development best practices.

### 🤖 AI-Powered Chatbot
A custom-built, intelligent assistant to guide visitors through my profile.
- **Powered by Google Gemini:** Utilizes the `gemini-2.5-flash` model for fast and contextually-aware conversations.
- **Domain-Specific Knowledge:** The chatbot is grounded with a comprehensive knowledge base of my skills, projects, and professional experience, ensuring accurate and relevant answers.
- **Multilingual Conversations:** Dynamically adapts its responses to the user's selected language.
- **On-Demand SEO Summary:** Features a unique function to generate a concise, keyword-rich SEO summary of my entire profile with a single click.
- **Interactive UI:** Includes a sleek interface with typing indicators, smooth message scrolling, and persistent chat history via `localStorage`.

### 🌍 AI-Powered Internationalization (i18n)
The entire portfolio can be translated into multiple languages in real-time.
- **Dynamic Translation with Gemini:** Leverages the Gemini API to translate all UI text, providing a truly localized experience.
- **Supported Languages:** Includes English, Spanish, Chinese (Simplified), Arabic, Japanese, and Korean.
- **Smart Caching:** Translated content is cached on the client-side to minimize API calls, reduce latency, and control costs on subsequent language switches.

### 🎨 Modern UI/UX & Design
A visually stunning and intuitive user experience is at the core of the design.
- **Dark/Light Mode:** A seamless theme toggle that respects user preferences and provides a comfortable viewing experience in any lighting.
- **Fully Responsive:** Meticulously crafted to look and function beautifully on all devices, from mobile phones to high-resolution desktops.
- **Engaging Animations:** Subtle, performant animations triggered on scroll using the `IntersectionObserver` API enhance user engagement without sacrificing performance.
- **Premium Aesthetics:** A unique "grainy" background texture, professional typography (Inter & Fira Code), and a vibrant, consistent color palette create a polished look and feel.

### 🛠️ Advanced SEO & Performance
Built from the ground up with Search Engine Optimization and speed in mind.
- **Comprehensive Structured Data:** Rich JSON-LD schemas for `Person`, `WebSite`, `Blog`, `Projects`, `Images`, and `Breadcrumbs` to improve search engine visibility and enable rich snippets.
- **Optimized Metadata:** Dynamic meta tags, Open Graph, and Twitter Cards ensure optimal social sharing and search engine presence.
- **Image Optimization:** Implements lazy loading and responsive images with `srcset` to reduce initial load times and conserve bandwidth.
- **Accessibility (a11y):** Adheres to WCAG standards with semantic HTML, ARIA attributes, focus management, a "skip to content" link, and support for `prefers-reduced-motion`.

### 🏗️ Robust Architecture
- **React & TypeScript:** A modern, type-safe frontend built with React for a scalable, component-based architecture.
- **Separation of Concerns:** A clean project structure that separates UI components, hooks, contexts, constants, and services.
- **Reusable Components:** Features a library of reusable components like modals, section layouts, and cards for consistency and maintainability.
